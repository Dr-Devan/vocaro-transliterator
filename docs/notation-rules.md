# 표기 규칙

규칙 버전: `vocaro-2026-10-02.1`.
기준: <https://vocaro.wikidot.com/guide:ja-ko-notation> (2026-10-02 확인).

## 처리 순서

1. 분석용 가나를 NFKC 및 히라가나로 통일합니다. 원문에는 적용하지 않습니다.
2. 품사상 조사인 は·へ·を는 わ·え·お로 읽습니다.
3. 요음과 외래어 조합을 최장 일치로 처리합니다.
4. 장음은 앞의 한글 모음을 반복합니다. エイ는 보존합니다. スー는 스으, キャー는 캬아입니다.
5. 촉음은 지정된 행 앞에서 받침 ㅅ으로 결합합니다. 문두·ん 뒤·그 외의 행 앞에서는 생략합니다.
6. ん은 받침 ㄴ으로 결합합니다. 결합할 음절이 없으면 원문을 남기고 검토 표시합니다.
7. 문장 부호는 발음에서 공백 처리하고 원문에서는 보존합니다.

## 범위와 예외

- 변환 단위는 분석기의 단어입니다. 단어 경계를 넘어 무조건 장음을 적용하지 않습니다.
- 인명·제목용 관용 표기는 자동으로 적용하지 않습니다. 발음 칸 기준으로 처리합니다.
- さん 등에 관해 일반 원칙과 예시의 적용 범위가 애매한 경우, 현재는 일반 음절 규칙을 사용합니다. 수동 발음 수정으로 예외를 지정할 수 있습니다.
- ファ 등은 기본 대응을 사용합니다. 원어에 따라 달라지는 예외는 수동 수정 대상으로 둡니다.
- 의성어, 단독 ん, 지원하지 않는 가나 확장 등은 확정된 발음으로 가장하지 않습니다.

예외를 추가할 때는 `backend/tests/test_transliteration.py`에 입력·기대값과 판단 근거를 함께 추가하고 규칙 버전을 올립니다.
