# 구현 결정

- **분석과 표기 분리:** 사전을 교체해도 한글 변환 규칙은 독립적으로 검증합니다.
- **호환 버전 고정:** SudachiPy 0.6.10과 SudachiDict Core 20250825를 함께 사용합니다. 새 사전 형식으로 자동 업데이트하지 않습니다.
- **UTF-32 코드 포인트 위치:** API의 start/end는 Python 문자열 기준입니다. 브라우저에서 원문 구간이 필요하면 Array.from(source)로 슬라이스해야 합니다. UTF-16 String.slice와 혼용하지 않습니다.
- **안전한 수정 보존:** 동일 행 위치·동일 원문·동일 토큰 경계에서만 수정 내용을 가져옵니다. 중복 후렴으로 수정을 잘못 이동시키지 않습니다.
- **행 출력 우선:** 행을 직접 고친 경우 토큰 편집을 잠그고 행 출력 복원 기능을 제공합니다.
- **단어별 처리:** 경계 간 장음 합치기는 하지 않습니다. 합성어 분할·보조동사 등은 품질 개선 대상으로 검수합니다.
- **API 입력 제한:** 최대 20,000자·500줄. 가나 수동 변환은 최대 1,000자. 토크나이저 접근은 잠금으로 직렬화합니다.
- **배포:** 하나의 컨테이너가 API와 프런트엔드 정적 파일을 제공합니다. 데이터베이스는 사용하지 않습니다.
- **초안:** 저장소 형식 버전을 붙입니다. 저장 실패는 표시하고 작업은 계속할 수 있도록 합니다.

## v0.2

- **읽기 우선순위:** 위치별 수동 지정 > 곡 사전의 가장 긴 정확 일치 > 형태소 분석기입니다.
- **범위 편집:** UI의 토큰 시작과 끝을 골라 하나로 합칩니다. API는 원문과 위치의 일치 및 중첩 여부를 검증합니다. 자동 결과로 복원하면 사전을 포함한 분석을 다시 적용합니다.
- **초안 v2:** 곡 사전과 번역을 함께 보관하고 v1을 마이그레이션합니다. JSON 가져오기는 토큰의 원문 범위, 데이터 타입, 길이와 버전을 검증합니다. 최대 파일 크기는 10MB입니다.
- **사전 수정:** 재변환 전까지 복사와 내보내기를 잠급니다. 수동으로 편집한 행 전체 출력은 그대로 유지합니다.
- **Wikidot:** `|| ... ||` 한 셀 표, 원문·발음·번역 3행 구조입니다. 빈 절에도 3행을 출력해 행별 스타일 순환을 유지합니다. 문법 문자는 엔티티 이스케이프하며, 기존 위키 마크업은 실행하지 않습니다. 실제 위키 렌더링은 최종 수동 검수 대상입니다.
- **실행:** `scripts/start.ps1`/`start.sh`는 현재 코드를 빌드하고 로컬 주소에서 제공합니다. `test.ps1`는 순차적으로 실패 즉시 중단하며 자신이 시작한 서버만 종료합니다.
- **분리된 ん:** `痛いんだ`가 `痛い / ん / だ`로 분리되어 단독 ん을 변환하지 못했던 문제를 수정했습니다. 토큰 변환은 ㄴ을 반환하고 행 출력은 앞 한글 음절에 결합하여 `이타인다`를 만듭니다. ん은 사용자가 지정한 원칙에 따라 항상 ㄴ입니다.
- **형태소 경계의 촉음:** 위키의 촉음 적용 조건을 토큰 내부에만 적용한 구현 오류를 수정했습니다. `待っ / て`, `言っ / た`에서는 다음 읽기를 참조하고, `君 / って`에서는 행 조합 시 앞 음절에 받침을 붙입니다. 형태소 경계 자체를 생략 근거로 삼지 않습니다. 수동 한글 수정은 우선하며, 명시적 구분자를 넘어서 결합하지 않습니다. 문두 `って`와 문말 `あっ`의 생략도 회귀 검사합니다.
- **읽기 후보:** Sudachi 사전의 정확 일치 항목 중 분석된 단어와 대분류 품사가 같은 읽기를 제공합니다. 私의 대명사 읽기에 명사의 シ를 섞지 않습니다. 선택한 읽기는 기존 수동 수정 및 곡 사전 흐름으로 저장합니다. 사전에 없는 특수 읽기는 직접 입력할 수 있습니다.
- **화면 테마:** 시스템 설정·라이트·다크를 지원하며 선택은 초안과 별도로 브라우저에 저장합니다. 홍보용 슬로건을 제거하고 편집 도구 중심으로 구성했습니다.

## 브라우저 및 GitHub Pages 배포

- 기존 컨테이너/API 배포를 대체하는 주 배포 경로는 GitHub Pages입니다. backend는 비교 검사 용도로 유지합니다.
- Sudachi.rs의 WASM 대응 포크를 커밋 42a5f2debb9785794eac9cd5eb0b730a47be0f97로 고정하고 Core 20250825 원본 YADA 사전을 그대로 읽습니다. 가벼운 대체 사전으로 바꾸지 않습니다.
- 다운로드·압축 해제·형태소 분석은 Worker에서 실행합니다. 약 72MB의 gzip을 Cache API로 저장하고 SHA-256을 확인합니다. 저장 실패는 현재 탭의 기능 사용을 막지 않습니다.
- 오프라인 최초 접속이나 새로고침은 지원 범위가 아닙니다. 준비된 탭에서는 네트워크 없이 분석할 수 있습니다.
- 한글 변환과 수동 읽기 계산은 TypeScript에서 수행하며 일본어 원문을 API로 보내지 않습니다.
- 코드 포인트 위치, 읽기 후보, 수동 지정 및 곡 사전 우선순위는 유지합니다. 기존 Python 결과 24행과 브라우저 결과를 자동 비교합니다.
- CI는 Pages 하위 경로에서 Python API 없이 전체 브라우저 검사를 통과한 정적 파일만 배포합니다.
